# Documentation

There are two kinds of documentation:

- **Help** for club admins, staff and shooters lives in the app under `/help`: public, in English, German, French and Italian, in the look of the app. Pages have a ?-button in their header that opens the matching help page in a sheet.
- **Operations and development** (this folder, `docs/`) are plain Markdown in English, read on GitHub.

## Help pages

| Path | Content |
|---|---|
| `web/src/help/en/` | the English pages, the source |
| `web/src/help/{de,fr,it}/` | the translated pages, generated by `make docs` and committed |
| `web/help/po4a.cfg`, `web/help/locales/` | translation setup, `help.pot` and the German, French and Italian PO files |
| `web/help/l10n.py` | runs po4a (in Debian through `make docs`) |
| `web/src/lib/help/nav.ts` | the sidebar: groups (translated through the app's Lingui catalogs) and the pages in order |
| `web/src/lib/help/markdown.ts` | loads and renders the pages with `marked` |
| `web/static/help/screenshots/` | screenshots made by `make docs`, committed |

The pages use plain Markdown plus what `markdown.ts` understands: `{#id}` after a heading, `{ .screenshot }` or `{ .screenshot .phone }` after an image, `!!! note "Title"` boxes with an indented body, and `<div class="grid" markdown>` around content shown side by side. Links between pages are relative `.md` links; links to pages that are not part of the help (e.g. this folder) are shown as plain text. `/help/changelog` shows `CHANGELOG.md`.

A new page goes into `web/src/help/en/`, into `nav.ts` and into `web/help/po4a.cfg`. A page gets a ?-button with `<PageHeader help="user-guide/x#anchor">`. Screenshots show invented people and clubs only. Update the help together with the feature it describes. `e2e/tests/help.spec.js` opens every page and checks every internal link, anchor and image.

## Translations

[po4a](https://po4a.org/) splits the English pages into paragraphs, headings, list items and table blocks in `web/help/locales/help.pot`; the translations live in `web/help/locales/{de,fr,it}.po`, the same gettext format as the app's catalogs.

- After changing an English page, run `make docs`. Changed paragraphs become untranslated (or fuzzy) in the PO files; translate them there and run `make docs` again to write the pages.
- A page is only written in a language when at least 80 % of it is translated; otherwise the help shows the English page with a note, so a half-finished translation never appears.
- Keep Markdown, links, `{#anchor}` ids, `++key++` shortcuts and code in a translation as they are. Headings that other pages link to carry an explicit `{#id}`, so links keep working when the heading text is translated.
- Bold UI labels must match the app's own translations in `web/src/locales/*.po`.
