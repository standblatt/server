# Keyboard and scanner

On a Mac, Cmd works wherever Ctrl is listed.

## Dashboard {#dashboard}

Also on helper links with a search box (ammunition desk, results clerk).

| Key | Does |
|---|---|
| F4 | clear the search field and jump into it |
| Esc | clear the search field |
| Enter after a [registration code](codes.md) | open the results of that registration; a code of another event or another shooter is refused |

A hand scanner types the QR code of a lane sheet or control strip followed by Enter, so scanning opens the results directly.

## Result fields {#results}

In the results of a registration, on **Enter results** and on scorer links.

| Key | Does |
|---|---|
| digits | the cursor moves to the next field as soon as another digit would exceed the maximum of the series, the shot or the mouches |
| Enter | save the programme |

So `96 93 97 88` can be typed without the mouse. After the last field the cursor moves to **Save**.

## Enter results {#quick-entry}

| Key | Does |
|---|---|
| Enter in **Shooter** | search at once and take the first hit |
| Esc in **Shooter** | clear the field |
| Enter in the results | save the result and get ready for the next shooter |

A barcode scanner that types the licence number and Enter picks the shooter.

## My training {#my-training}

While a session is open on a computer, unless the focus is in a text field:

| Key | Does |
|---|---|
| 0–9 | type the series total or the shot value |
| . or , | decimal point |
| Backspace | delete the last digit; with nothing typed, take back the last value |
| Enter | take the number as it is, like **Next** |

With whole-number scoring up to 10, shot values are tapped on the buttons; the keyboard types series totals there.

## Print form editor {#print-forms}

Except while typing in a field; Ctrl+S works there too.

| Key | Does |
|---|---|
| Arrow keys | move the selection by 0.5 mm, with Shift by 5 mm |
| Ctrl+Z / Ctrl+Y | undo / redo |
| Ctrl+Shift+Z | redo |
| Ctrl+A | select everything |
| Ctrl+D | duplicate |
| Delete or Backspace | delete the selection |
| Esc | clear the selection |
| Ctrl+S | save |
| Ctrl+mouse wheel | zoom |
| Shift or Ctrl and click | add an element to the selection or remove it |
| Alt while dragging | place freely, without snapping |
