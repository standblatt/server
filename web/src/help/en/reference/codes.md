# Codes and barcodes

## Registration code (QR)

Lane sheets and control strips carry a QR code with

```text
REGCODEAAAA<registration>AAAAL<license or 0>
```

for example `REGCODEAAAA42AAAAL100109`. A hand scanner types it into the search field of the dashboard and presses Enter; Standblatt opens the results of that registration. The license part guards against a code from another shooter; a code of another event is refused.

## Programme barcode (Interleaved 2 of 5)

A programme can have a barcode, printed as Interleaved 2 of 5 next to the programme on the lane sheet (only the digits count, padded to an even number of digits). Electronic scoring systems use it to pick the programme.
