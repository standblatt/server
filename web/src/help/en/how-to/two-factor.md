# Protect your login with a second factor

You need this when a password alone is not enough for your account, e.g. as a club admin. After the password, Standblatt then asks for the six-digit code of an authenticator app (Google Authenticator, Aegis, 1Password and the like).

## Switch it on {#on}

1. Install an authenticator app on your phone.
2. Open **Account** (in the user menu at the bottom of the sidebar, on the start page or in My training's sidebar).
3. Under **Second factor**, click **Set up**.
4. Scan the QR code with the app. If it cannot scan, type the key shown below the code into the app.
5. Enter the code the app shows in **Code from the app** and click **Switch on**.

From now on, the login asks for **Code from your authenticator app** after the password. Each code works once.

![Account](../images/screenshots/account.png){ .screenshot }

If **Second factor** is missing on the page, the operator has switched the feature off for the whole server.

## Switch it off {#off}

1. Open **Account**.
2. Under **Second factor**, click **Switch off**, enter your password and confirm with **Switch off**.

## Lost the phone {#lost}

Without the app you cannot log in. Ask the platform operator to reset the second factor in the admin panel (**Reset second factor** on your user), then log in with the password and set it up again on the new phone.
