# Utilisateurs

**Utilisateurs** (admins seulement) liste les comptes ayant accès à la société et leur rôle.

![Utilisateurs](../images/screenshots/users.png){ .screenshot }

- **Inviter par e-mail** : collez une ou plusieurs adresses (séparées par
  des virgules ou une par ligne, jusqu’à 300) et choisissez le rôle. Les
  personnes sans compte reçoivent un e-mail avec un lien pour définir leur
  mot de passe (valable sept jours) et se connectent ensuite avec leur
  adresse e-mail ; les comptes existants sont ajoutés à la société et
  informés par e-mail. La liste sous le formulaire indique ce qui s’est
  passé pour chaque adresse. Les e-mails partent à environ quatre par
  seconde, une grande liste prend donc une minute.
- **Ajouter un utilisateur** : l’ancienne méthode pour un compte sans e-mail
  : un compte existant est ajouté par son nom d’utilisateur ; pour un
  nouveau compte, saisissez aussi un mot de passe (au moins 10 caractères).
- **Rôle** : *Admin* gère stands, manifestations, programmes et utilisateurs
  ; *Personnel* conduit les manifestations (voir
  [Notions](../getting-started/concepts.md#clubs-users-and-roles)).
- **Retirer** supprime l’accès à cette société ; le compte lui-même reste et
  garde ses autres sociétés.

Les comptes sont globaux : un compte est supprimé par l’exploitant de la
plateforme dans le [panneau
d’administration](../admin-guide/admin-panel.md). Un mot de passe oublié se
réinitialise avec **Mot de passe oublié ?** sur la page de connexion si le
compte a une adresse e-mail confirmée, sinon par l’exploitant.
