# Inscriptions

Une inscription place un tireur sur une cible avec les programmes qu’il
tire. Ouvre-la depuis la recherche du tableau de bord (**Inscrire …**).

![Fenêtre d’inscription](../images/screenshots/registration.png){
.screenshot }

## Cible

Choisis une cible libre dans la grille ou laisse vide : le tireur attend
alors que tu lui attribues une cible en modifiant l’inscription.

- Les cibles occupées ou hors service ne peuvent pas être choisies.
- Une cible réservée demande une confirmation avant d’être utilisée.

## Programmes

Les programmes de la manifestation avec leur prix pour la catégorie d’âge du
tireur. Les programmes sans prix pour cette catégorie sont grisés (*pas pour
cette catégorie d’âge*).

- Les **variantes** (même nom de programme) apparaissent comme un choix
  unique.
- Un programme **combinable** propose *reprendre N passes de …* : coche-le
  et choisis exactement N passes de l’autre programme. L’autre programme est
  ajouté automatiquement s’il n’est pas encore choisi.
- Le **total** en bas additionne les prix.

## Tireur déjà inscrit

Si le tireur est ou était déjà inscrit à cette manifestation, une note liste
ces inscriptions avec leurs programmes et un lien pour les ouvrir. Les
programmes déjà réservés sont verrouillés (*déjà inscrit*, ou *plus de
tentatives* pour les programmes à plusieurs
[tentatives](programmes.md#attempts)) ; un tireur peut quand même tirer une
autre variante dans une inscription séparée.

## Impression

*Imprimer la feuille de stand* et *Imprimer la bande de contrôle* sont cochés par défaut (ils n’apparaissent que tant que les modules *Feuille de stand* et *Bande de contrôle* sont activés, voir [Modules](events.md#modules)) : les documents s’impriment sur les imprimantes du stand juste après l’inscription, ou s’ouvrent en PDF si aucune imprimante n’est configurée (voir [Impression](printing.md)). Les [modèles d’impression](print-forms.md#certificates) de la société qui impriment une inscription, p. ex. une carte de participant, ajoutent chacun un bouton.

## Modifier et supprimer

Ouvre une inscription depuis le tableau de bord (**Modifier**) ou depuis les
résultats (*Modifier l’inscription*) pour changer la cible ou les
programmes. Les programmes qui ont déjà des résultats ne peuvent pas être
retirés ; changer les passes choisies d’une combinaison copie les nouvelles
passes. **Supprimer** retire l’inscription avec ses résultats après
confirmation.
