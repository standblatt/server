# Protéger ta connexion par un deuxième facteur

Tu en as besoin quand un mot de passe seul ne suffit pas pour ton compte,
p. ex. en tant qu’admin d’une société. Après le mot de passe, Standblatt
demande alors le code à six chiffres d’une app d’authentification (Google
Authenticator, Aegis, 1Password et autres).

## L’activer {#on}

1. Installe une app d’authentification sur ton téléphone.
2. Ouvre **Compte** (dans le menu utilisateur en bas de la barre latérale,
   sur la page d’accueil ou dans la barre latérale de Mon entraînement).
3. Sous **Deuxième facteur**, clique sur **Configurer**.
4. Scanne le code QR avec l’app. Si elle ne peut pas le scanner, tape dans
   l’app la clé affichée sous le code.
5. Saisis le code que montre l’app dans **Code de l’app** et clique sur
   **Activer**.

Désormais, la connexion demande le **Code de ton app d’authentification**
après le mot de passe. Chaque code ne fonctionne qu’une fois.

![Compte](../images/screenshots/account.png){ .screenshot }

Si **Deuxième facteur** manque sur la page, l’exploitant a désactivé la
fonction pour tout le serveur.

## Le désactiver {#off}

1. Ouvre **Compte**.
2. Sous **Deuxième facteur**, clique sur **Désactiver**, saisis ton mot de
   passe et confirme avec **Désactiver**.

## Téléphone perdu {#lost}

Sans l’app, tu ne peux pas te connecter. Demande à l’exploitant de la
plateforme de réinitialiser le deuxième facteur dans le panneau
d’administration (**Réinitialiser le deuxième facteur** sur ton
utilisateur), puis connecte-toi avec le mot de passe et configure-le à
nouveau sur le nouveau téléphone.
