# Clavier et scanner

Sur un Mac, Cmd fonctionne partout où Ctrl est indiqué.

## Tableau de bord {#dashboard}

Aussi sur les liens d’aide avec un champ de recherche (distribution de
munition, bureau des résultats).

| Touche | Effet |
|---|---|
| F4 | vide le champ de recherche et y place le curseur |
| Échap | vide le champ de recherche |
| Entrée après un [code d’inscription](codes.md) | ouvre les résultats de cette inscription ; un code d’une autre manifestation ou d’un autre tireur est refusé |

Un scanner manuel tape le code QR d’une feuille de stand ou d’une bande de
contrôle suivi d’Entrée ; scanner ouvre donc directement les résultats.

## Champs de résultats {#results}

Dans les résultats d’une inscription, sous **Saisir les résultats** et sur
les liens de cibarre.

| Touche | Effet |
|---|---|
| chiffres | le curseur passe au champ suivant dès qu’un chiffre de plus dépasserait le maximum de la passe, du coup ou des mouches |
| Entrée | enregistre le programme |

Ainsi, `96 93 97 88` se tape sans la souris. Après le dernier champ, le
curseur passe sur **Enregistrer**.

## Saisir les résultats {#quick-entry}

| Touche | Effet |
|---|---|
| Entrée dans **Tireur** | cherche aussitôt et prend le premier résultat |
| Échap dans **Tireur** | vide le champ |
| Entrée dans les résultats | enregistre le résultat et se prépare pour le tireur suivant |

Un scanner de codes-barres qui tape le numéro de licence et Entrée choisit
le tireur.

## Mon entraînement {#my-training}

Tant qu’une séance est ouverte sur un ordinateur, sauf si le focus est dans
un champ de texte :

| Touche | Effet |
|---|---|
| 0–9 | tape le total de la passe ou la valeur du coup |
| . ou , | virgule décimale |
| Retour arrière | efface le dernier chiffre ; si rien n’est tapé, reprend la dernière valeur |
| Entrée | prend le nombre tel quel, comme **Suivant** |

Avec un comptage entier jusqu’à 10, les valeurs des coups se touchent sur
les boutons ; le clavier y tape les totaux des passes.

## Éditeur de modèles d’impression {#print-forms}

Sauf pendant la saisie dans un champ ; Ctrl+S y fonctionne aussi.

| Touche | Effet |
|---|---|
| Flèches | déplacent la sélection de 0.5 mm, avec Maj de 5 mm |
| Ctrl+Z / Ctrl+Y | annuler / rétablir |
| Ctrl+Maj+Z | rétablir |
| Ctrl+A | tout sélectionner |
| Ctrl+D | dupliquer |
| Suppr ou Retour arrière | supprimer la sélection |
| Échap | annuler la sélection |
| Ctrl+S | enregistrer |
| Ctrl+molette | zoomer |
| Maj ou Ctrl et clic | ajouter un élément à la sélection ou l’en retirer |
| Alt pendant le glisser | placer librement, sans aimantation |
