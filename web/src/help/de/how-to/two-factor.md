# Die Anmeldung mit einem zweiten Faktor schützen

Das brauchst du, wenn ein Passwort allein für dein Konto nicht reicht,
z. B. als Vereins-Admin. Nach dem Passwort fragt Standblatt dann nach dem
sechsstelligen Code einer Authenticator-App (Google Authenticator, Aegis,
1Password und ähnliche).

## Einschalten {#on}

1. Installiere eine Authenticator-App auf deinem Handy.
2. Öffne **Konto** (im Benutzermenü unten in der Seitenleiste, auf der
   Startseite oder in der Seitenleiste von Mein Training).
3. Klicke unter **Zweiter Faktor** auf **Einrichten**.
4. Scanne den QR-Code mit der App. Kann sie nicht scannen, tippe den unter
   dem Code angezeigten Schlüssel in die App.
5. Gib den Code, den die App zeigt, in **Code aus der App** ein und klicke
   auf **Einschalten**.

Ab jetzt fragt die Anmeldung nach dem Passwort nach dem **Code aus deiner
Authenticator-App**. Jeder Code funktioniert einmal.

![Konto](../images/screenshots/account.png){ .screenshot }

Fehlt **Zweiter Faktor** auf der Seite, hat der Betreiber die Funktion für
den ganzen Server ausgeschaltet.

## Ausschalten {#off}

1. Öffne **Konto**.
2. Klicke unter **Zweiter Faktor** auf **Ausschalten**, gib dein Passwort
   ein und bestätige mit **Ausschalten**.

## Handy verloren {#lost}

Ohne die App kannst du dich nicht anmelden. Bitte den Plattformbetreiber,
den zweiten Faktor im Admin-Panel zurückzusetzen (**Zweiten Faktor
zurücksetzen** bei deinem Benutzer), melde dich dann mit dem Passwort an und
richte ihn auf dem neuen Handy wieder ein.
