# Tastatur und Scanner

Auf einem Mac funktioniert Cmd überall, wo Ctrl steht.

## Dashboard {#dashboard}

Auch auf Helferlinks mit Suchfeld (Munitionsausgabe, Resultaterfassung).

| Taste | Wirkung |
|---|---|
| F4 | leert das Suchfeld und springt hinein |
| Esc | leert das Suchfeld |
| Enter nach einem [Anmeldecode](codes.md) | öffnet die Resultate dieser Anmeldung; ein Code eines anderen Anlasses oder eines anderen Schützen wird abgelehnt |

Ein Handscanner tippt den QR-Code eines Standblatts oder Kontrollstreifens,
gefolgt von Enter, so öffnet Scannen direkt die Resultate.

## Resultatfelder {#results}

In den Resultaten einer Anmeldung, unter **Resultate erfassen** und auf
Warner-Links.

| Taste | Wirkung |
|---|---|
| Ziffern | der Cursor springt ins nächste Feld, sobald eine weitere Ziffer das Maximum der Passe, des Schusses oder der Mouchen überschreiten würde |
| Enter | speichert das Programm |

So lässt sich `96 93 97 88` ohne Maus eintippen. Nach dem letzten Feld
springt der Cursor auf **Speichern**.

## Resultate erfassen {#quick-entry}

| Taste | Wirkung |
|---|---|
| Enter in **Schütze** | sucht sofort und nimmt den ersten Treffer |
| Esc in **Schütze** | leert das Feld |
| Enter in den Resultaten | speichert das Resultat und macht bereit für den nächsten Schützen |

Ein Barcodescanner, der die Lizenznummer und Enter tippt, wählt den
Schützen.

## Mein Training {#my-training}

Solange auf einem Computer eine Einheit offen ist, ausser der Fokus liegt in
einem Textfeld:

| Taste | Wirkung |
|---|---|
| 0–9 | tippt das Passentotal oder den Schusswert |
| . oder , | Dezimalpunkt |
| Backspace | löscht die letzte Ziffer; ist nichts getippt, nimmt den letzten Wert zurück |
| Enter | übernimmt die Zahl, wie sie ist, wie **Weiter** |

Bei Ganzzahlwertung bis 10 werden Schusswerte auf den Knöpfen getippt; die
Tastatur tippt dort Passentotale.

## Editor für Druckvorlagen {#print-forms}

Ausser beim Tippen in einem Feld; Ctrl+S funktioniert auch dort.

| Taste | Wirkung |
|---|---|
| Pfeiltasten | verschieben die Auswahl um 0.5 mm, mit Shift um 5 mm |
| Ctrl+Z / Ctrl+Y | rückgängig / wiederholen |
| Ctrl+Shift+Z | wiederholen |
| Ctrl+A | alles auswählen |
| Ctrl+D | duplizieren |
| Entf oder Backspace | Auswahl löschen |
| Esc | Auswahl aufheben |
| Ctrl+S | speichern |
| Ctrl+Mausrad | zoomen |
| Shift oder Ctrl und Klick | ein Element zur Auswahl hinzufügen oder daraus entfernen |
| Alt beim Ziehen | frei platzieren, ohne Einrasten |
